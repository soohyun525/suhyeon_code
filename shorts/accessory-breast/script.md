# 쇼츠 대본: "임신했는데 겨드랑이에 이게 뭐야?!" (약 15초, 9:16)

## 컨셉
임신 중기 젊은 엄마가 거울 앞에서 겨드랑이 쪽 멍울을 발견하고 깜짝 놀람 → 알고 보니 '부유방'.
가볍고 공감 가는 톤, 마지막에 정보 한 줄로 마무리.

## 대본

| 시간 | 화면 | 대사 / 자막 |
|---|---|---|
| 0–3초 | 배가 살짝 나온 20대 여성이 욕실 거울 앞에서 민소매 차림으로 팔을 들다가 겨드랑이 아래를 만져봄 | (혼잣말) "어…? 이거 뭐야?" |
| 3–7초 | 클로즈업: 눈이 휘둥그레지는 얼굴, 휴대폰을 집어 다급하게 검색 | "겨드랑이에 멍울이…? 혹시 큰 병이면 어떡해!" |
| 7–11초 | 산부인과 진료실. 의사가 웃으며 설명, 여성이 안도하며 배를 쓰다듬음 | 의사: "부유방이에요. 임신하면 호르몬 때문에 커질 수 있어요." |
| 11–15초 | 집 소파, 여성이 카메라를 보며 웃음 | "나만 몰랐어?! 임산부 여러분, 놀라지 말고 병원 먼저 가봐요!" |

## 화면 자막 (편집 시 추가)
- 상단 고정: **임신하고 겨드랑이에 멍울이?!**
- 마지막: *부유방은 흔하지만, 멍울이 생기면 꼭 진료를 받아보세요.*
