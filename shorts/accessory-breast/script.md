# 쇼츠 대본: "소녀였던 내가… 알고 보니 포유류?!" (약 18초, 9:16)

## 컨셉
'이슬만 먹고 사는 소녀'라고 믿었던 엄마가, 임신 중 겨드랑이 부유방을 발견하고
"나… 포유류였구나"를 깨닫는 코믹 쇼츠. 마지막은 동물 다큐 내레이션으로 마무리.

## 대본

| 시간 | 장면 | 대사 / 자막 |
|---|---|---|
| 0–2초 | **회상(10년 전)**: 핑크빛 화면, 세일러복 양갈래 소녀가 반짝이는 눈으로 이슬방울을 바라봄 | 소녀: "나는 이슬만 먹고 사는 소녀였는데…" |
| 2–5초 | **현재, 욕실 거울**: 배 나온 엄마가 팔을 들다 겨드랑이에서 멍울 발견 (?! 효과음) | 엄마: "근데 겨드랑이에 이건 뭐야?!" |
| 5–10초 | **산부인과**: 의사가 '젖줄(유선)' 그림을 가리키며 설명 | 의사: "부유방이에요. 젖줄이 겨드랑이까지 있어서, 임신하면 커지기도 해요." → 엄마: (젖…줄?) |
| 10–13초 | **깨달음**: 둥·둥·둥! 3단 줌인, 번개 효과 | 엄마: "젖줄…? 그럼 나… 포유류였어?!" |
| 13–18초 | **동물 다큐**: 노을 진 초원, 소·강아지·고양이가 "어서 와~" 환영. 하단 자막 "엄마(임신 중) · 포유강 영장목 사람과" | 내레이션(낮은 목소리): "그렇게 소녀는, 포유류가 되었다." |
| 마지막 | 엔딩 카드 | "부유방, 생각보다 흔해요 / 그래도 새로 생긴 멍울은 꼭 진료로 확인하세요!" |

## 상단 고정 제목
