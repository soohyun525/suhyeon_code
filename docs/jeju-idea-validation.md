# 아이디어 필요성 검증 — 청년 제주 이주·정착 동행 Agent

> 작성일 2026-11-11 · 대상: `docs/jeju-iju-agent-plan.md`의 기획안
> 수치는 대부분 언론 보도와 검색 요약에서 가져왔다. 일부 기사는 작업 환경에서 원문을 열지 못했으므로 기획서에 인용하기 전 원문 확인이 필요하다.

## 1. 결론

**문제는 실재하지만, 지금의 틀("청년이 제주에 집을 짓고 귀농하도록 모든 것을 알아봐 준다")은 세 군데에서 약하다.** 방향을 "이주를 돕는다"에서 **"이주 전에 현실을 검증하고, 그 동네에 없는 일을 찾아 준다"**로 좁히면 근거, 데이터, 차별성이 모두 맞는다.

| 판정 | 기획 요소 | 근거 |
|---|---|---|
| 강화 | 삶의 변화를 미리 교육·체험 | 실패는 이주 후에 일어난다 (2.2) |
| 강화 | 동네 선택 | 센터 데이터가 읍면동 단위로 뒷받침한다 (2.5) |
| 강화 (재정의) | 직업·사업 + 지역 기여 | "마을에 없는 것"을 찾는 기능 하나로 합친다 (2.3) |
| 축소 | 이주에 필요한 모든 것 안내 | 공공 서비스와 정면으로 겹친다 (2.4) |
| 축소 | 청년 커뮤니티 매칭 | 필요성은 확인되나 뒷받침할 데이터가 없다 |
| 제외 | 별장·집 짓기 절차 | 데이터가 없고, 주거비가 이탈 사유인 지역에서 설득력이 낮다 |

## 2. 검증 결과

### 2.1 시장 방향: 들어오는 사람이 줄고 있다

- 2025년 제주 순유출 4,273명. 20대가 절반을 넘어 역대 최대.
- 제주 귀촌인은 2021년 12,307명 → 2025년 9,731명으로 4년 연속 감소(-20.9%). 같은 해 전남(+7.5%)·전북(+1.7%)은 늘었다.
- 제주 귀농가구는 2025년 137가구(전 연령). 2024년에는 전년 대비 40.7% 급감했다.
- 제주 청년 인구는 2020년 약 16.5만 명 → 2025년 약 14.3만 명.

**해석**: "청년 귀농인"만 대상으로 하면 연 100가구 남짓한 시장이다. 반면 유입 감소 자체는 도의 정책 과제이므로 주제의 정책 적합성은 높다. 대상을 귀농에서 **귀촌·체류(한달살이, 워케이션) 청년**으로 넓혀야 한다.

### 2.2 실패 원인: 정보 부족이 아니라 이주 후의 소득과 관계

- 제주연구원 정착주민 조사(2021, 410명): 28.3%가 제주를 떠날 계획. 이유는 타 지역 취업·발령 29.6%, 낮은 소득 15.8%, 물가·주거비 13.2%, 자녀 교육 12.3%.
- 같은 조사에서 72.9%가 지역 공동체 활동에 참여하지 않는다. 이유는 바빠서, 활동을 몰라서.
- 전국 통계: 최근 5년 내 귀촌인의 8.5%(19.1만 명), 귀농인의 3.6%가 도시로 되돌아갔다.
- 행안부 청년마을: 지역살이 참여 5,575명 중 실제 정착 242명(약 4%). "살아보기에서 눌러앉기 사이의 간극"이 지적된다.
- 인터뷰 사례: 이주 1년 만에 떠나는 27세(월수입 70만 원 선), 외지인이라는 이유로 마을회비를 2~3배 요구받은 사례, "주거비가 서울과 큰 차이 없고 연세 구조라 대출이 어렵다"는 창업자.
- 제주대 김형아 교수: 제주 청년 귀농인은 수익 발생까지 최소 4년이 걸리는데 그 기간 지원이 부족하다.

**해석**: 사용자가 떠올린 다섯 가지 중 "미리 교육받기"와 "커뮤니티"가 근거가 가장 강하다. "알아봐 주기"는 실패 원인과 거리가 멀다.

### 2.3 소득 경로: 이주 청년의 전형적 선택지가 가장 위험하다

- 제주 청년 평균 임금 월 226만 원, 전국 평균의 85.6%로 17개 시도 중 최저(한국은행 제주본부).
- 청년 52.7%가 "연봉 3,800만 원 수도권 일자리"를 "2,500만 원 제주 일자리"보다 선택(2025 제주도민 일자리 인식 실태조사).
- 제주 숙박업 초과공급 약 4.7만 실. 농어촌민박 폐업률 2023~2025년 평균 8.2%(다른 숙박업 2.5%).
- 숙박·음식점업 청년 종사자는 2023년 대비 28.2% 감소. 전국 커피음료점 수는 2025년 1분기 처음으로 감소.

**해석**: 기존 기획의 "카페·스테이 창업" 페르소나는 통계상 실패 확률이 가장 높은 경로다. Agent가 이 선택을 그대로 도우면 해가 된다. **과밀 업종을 경고하고 마을에 비어 있는 수요를 찾아 주는 기능**이 있어야 하고, 이것이 "지역 기여"와 같은 기능이 된다.

### 2.4 중복: 2026년에 공공 서비스가 같은 자리에 들어왔다

| 서비스 | 시기 | 겹치는 부분 |
|---|---|---|
| 제주도 귀농귀촌종합지원센터 (표선면) | 2026-10-31 개소 | 준비~정착 원스톱 상담, 단계별 교육, 실습농장, 미리 살아보기, 마을 융화사업 |
| 그린대로 (농정원) | 2026년 AI 도입 계획 | 상담 자동화, 맞춤형 교육 추천, 시뮬레이션 |
| 제주청년플랫폼 | 2026년 개편 | 연령·거주지·관심사 기반 AI 정책 추천 |
| 제주 인구정책 통합 플랫폼 | 2026-01 운영 | 생활인구 분석, 워케이션·런케이션 예약 |

**해석**: "이주에 필요한 모든 것을 알아봐 준다"는 이제 센터의 공식 업무다. 경쟁하지 말고 **센터 상담사가 상담 중에 쓰는 데이터 도구**로 자리를 잡는 편이 낫다. 우수작이 제주빅데이터센터에 탑재된다는 대회 조건과도 맞는다. 기존 서비스 중 읍면동 단위 생활·상권 데이터로 "이 동네에서 1년을 살면 어떤가"를 보여 주는 것은 확인되지 않았다.

### 2.5 데이터 적합성

확인된 센터·허브 데이터: 내국인 카드 이용 현황, 버스 노선별 이용, 기업 거래처, 업종별 매장 수, 휴폐업, 읍면동 단위 내국인 유동인구.

| 기능 | 데이터로 뒷받침되는가 |
|---|---|
| 동네 생활 여건 비교 (교통, 상권, 유동인구) | 가능 |
| 1년 생활 시뮬레이션 (월별 혼잡·소비) | 가능 |
| 업종 과밀·폐업 위험, 마을 빈자리 | 가능 |
| 집·토지·건축 | 확인된 데이터 없음 |
| 커뮤니티·모임 | 확인된 데이터 없음 |
| 지원사업 자격 | 데이터가 아니라 공고문 정리 작업 |

### 2.6 경쟁 출품작

- DAKER 페이지 기준 참가 434명, 제출 36건 (검색 시점 수치).
- 공개된 출품작 2건: 동네 창업·장사 진단 Agent(센터 업종·휴폐업·카드 데이터 사용), 자연어 데이터 분석 길잡이.
- 두 작품 모두 Streamlit 기반이며 센터 PC에서 실행하는 것을 전제로 한다. 한 작품은 데이터 반출 기준 검사기와 키 없이 동작하는 오프라인 모드를 넣었다.

**해석**: 상권 진단 단독은 이미 있다. 평가가 Elo 방식(작품 간 비교로 추정)이므로 "누구의 어떤 결정을 돕는가"가 한 문장으로 구별되어야 한다. 이주·정착은 공개 출품작 중에는 보이지 않는다.

## 3. 대안 검토

| 안 | 내용 | 필요성 | 데이터 | 차별성 | 판단 |
|---|---|---|---|---|---|
| A. 현행 유지 | 청년 귀농·별장·커뮤니티 종합 안내 | 중 | 낮음 | 낮음 (센터와 중복) | 비추천 |
| **B. 이주 전 현실검증 + 마을 빈자리** | 동네별 1년 리허설, 소득 경로 생존 진단, 마을에 없는 일 제안 | 높음 | 높음 | 높음 | **추천** |
| C. 제주 청년 유출 방지 일자리 매칭 | 떠나려는 도내 청년 대상 | 가장 높음 | 낮음 (채용 데이터 없음) | 중 | 비추천. 원인이 임금 격차라 Agent로 풀기 어렵다 |
| D. 농어촌민박·소상공인 폐업 위험 진단 | 기존 사업자 대상 | 높음 | 높음 | 낮음 (공개 출품작과 중복) | B의 일부로 흡수 |

## 4. 추천안: "제주살이 리허설" (가칭)

**이주를 결정하기 전에, 그 동네에서의 1년과 그 일로 먹고살 수 있는지를 데이터로 먼저 살아 보게 한다.**

1. **동네 고르기** — 생활 방식 인터뷰 → 읍면동 3곳 비교 (버스 접근성, 생활 상권, 유동인구 계절 변동)
2. **1년 리허설** — 선택한 동네의 월별 혼잡·소비·이동 여건을 달력으로 제시하고, 이주자가 자주 떠나는 이유(소득, 주거비, 고립)에 대한 준비도를 진단
3. **마을 빈자리 찾기** — 업종별 매장 수·휴폐업·카드 소비로 과밀 업종을 경고하고, 그 동네에 없어서 주민이 다른 곳에서 소비하는 업종·서비스를 제시 → 사용자의 직업과 지역 기여가 여기서 만난다
4. **결과 리포트** — 이주 권고/보류 판단 근거, 준비할 것, 귀농귀촌종합지원센터·청년플랫폼의 다음 연결처

사용자 원안의 다섯 요소는 이렇게 남는다.

| 원안 | 추천안에서 |
|---|---|
| 모든 것을 알아봐 줌 | 리포트 끝의 "다음 연결처"로 축소. 상담은 센터에 넘긴다 |
| 미리 교육받음 | 핵심 기능 (1년 리허설, 준비도 진단) |
| 커뮤니티·동네 선택 | 동네 선택은 핵심. 커뮤니티는 동네별 거점 목록으로 제공 |
| 지역사회 기여 | 마을 빈자리 찾기 |
| 직업·사업 | 마을 빈자리 찾기 + 과밀 경고 |

대상은 "귀농 청년"에서 **제주 이주·두 지역 살이를 고민하는 청년과, 그들을 상담하는 센터 상담사**로 바꾼다. "별장"은 도의 정책 용어인 두 지역 살이·체류인구로 표현을 바꾸는 편이 심사에 유리하다.

## 5. 이 검증의 한계

- 대회 페이지(daker.ai)와 다수 언론사 원문을 열지 못해 검색 요약에 의존했다. 특히 한국은행 제주본부 보고서 수치(임금, 숙박업)는 2차 보도 기준이다.
- 이주민 재이주 의향 조사는 2021년 자료다. 이후 유출이 심해졌으므로 방향은 같을 가능성이 높지만 최신 수치는 아니다.
- 센터 데이터 목록은 공개 출품작과 보도에서 확인한 일부다. 보도에는 "센터 전용 65종", 대회 안내에는 "목록 1,259종"으로 나와 범위가 다르다. 실제 목록에서 읍면동 단위 제공 여부를 확인해야 2.5의 판단이 확정된다.
- 평가 방식(Elo)의 비교 주체가 심사위원인지 참가자인지 확인하지 못했다.
- 청년 당사자 인터뷰는 기사 인용 수준이다. 가능하면 제출 전 이주 경험자 2~3명에게 리포트 시안을 보여 주는 것이 좋다.
