# 큐피트 — 브랜드·디자인 전략 (초안 v0.1)

살아 있는 디자인 시스템: `/cupid/system` · 토큰: `src/app/cupid/tokens.css` · 서비스: `/cupid`

## 1. 한 줄

**첫 데이트는 에이전트가 잡아옵니다.**
큐피트는 "누구와 대화할까"가 아니라 "언제 어디서 만날까"를 결과로 내놓는 소개팅 서비스다.

## 2. 누구의 어떤 문제인가

| | 내용 |
|---|---|
| 대상 | 20대 후반~30대 직장인. 소개팅 앱을 써봤고, 지쳤다. |
| 문제 | 넘기고, 매칭되고, 인사하고, 흐지부지된다. 만나기까지의 대화가 일이다. |
| 약속 | 그 일을 에이전트가 대신한다. 사람은 "승인"만 누른다. |
| 불안 | AI가 내 정보를 떠벌리지 않을까, 내 뜻과 다르게 약속을 잡지 않을까. |
| 답 | 세 가지 약속 — 안 되는 조건은 밖으로 나가지 않는다 / 겹치는 시간만 드러난다 / 확정은 사람이 한다. |

## 3. 자리 잡기

기존 앱은 **설렘을 파는 화면**(사진, 넘기기, 하트, 분홍 그라데이션)이다. 큐피트는 **약속을 전하는 문서**다.

- 사진 대신 **글과 날짜**가 주인공이다.
- 넘기기 대신 **초대장 한 장**이 결과물이다.
- 게임 같은 보상 대신 **조용한 확신**을 준다.

그래서 화면은 앱보다 편지·초대장·기록에 가깝게 만든다.

## 4. 성격

| 큐피트는 | 큐피트는 아니다 |
|---|---|
| 일 잘하는 주선자 | 분위기 띄우는 사회자 |
| 조용하고 분명하다 | 들뜨고 과장한다 |
| 결과를 먼저 말한다 | 기대감을 끌며 뜸 들인다 |
| 안 된 이유도 말해준다 | 실패를 숨긴다 |

## 5. 디자인 원칙

1. **결과가 제일 크다.** 한 화면에서 가장 큰 글자는 언제나 결과(날짜, 건수, 이름)다.
2. **로즈는 한 화면에 한 번.** 브랜드색은 가장 중요한 버튼 하나, 내 에이전트의 말, 확정 상태에만.
3. **상자보다 선.** 내용을 카드에 가두지 않고 가는 선과 여백으로 나눈다. 상자는 초대장 하나뿐이다.
4. **숨긴 것을 보여준다.** 무엇을 말하고 무엇을 말하지 않는지를 화면에 적는다. 잠긴 항목은 잠겼다고 쓴다.
5. **움직임은 두 순간에만.** 에이전트가 일할 때, 약속이 잡혔을 때.

## 6. 브랜드 요소

### 로고
두 점과 그 사이의 호. 먹색 점은 나, 로즈 점은 상대, 호는 오가는 에이전트. 같은 그림이 3D 배경(두 점과 점선)과 초대장의 도장으로 반복된다. 하트·화살·날개는 쓰지 않는다.

### 포인트 컬러 — 로즈 레터 `#DC2660`
당근 주황에서 바꿨다. 고른 이유:

- **연애의 색이되 분홍이 아니다.** 흔한 핫핑크·그라데이션보다 깊은 장미색으로, 봉투의 밀랍 도장을 떠올리게 한다.
- **읽힌다.** 흰 글자를 올려도 4.7:1, 흰 바탕 위 글자로도 4.7:1 (이전 주황 버튼은 2.9:1).
- **하나로 충분하다.** 100~900 단계만 두고 보조색은 만들지 않는다. 나머지는 Seed의 회색.

| 단계 | 값 | 쓰임 |
|---|---|---|
| 100 | `#FFF0F4` | 옅은 바탕, 약한 배지 |
| 200 | `#FFDDE6` | 눌린 옅은 바탕 |
| 300 | `#FFBCCD` | 약한 테두리 |
| 400 | `#FF8FAB` | 장식 |
| 500 | `#F55A84` | 장식 |
| **600** | **`#DC2660`** | **기준색 — 버튼, 강조 글자, 3D의 두 점** |
| 700 | `#B81A4E` | 눌린 버튼 |
| 800 | `#8F143E` | — |
| 900 | `#5F0E2A` | 옅은 바탕 위 글자 |

### 글자
Pretendard 하나. 제목 800, 본문 400~500. 크기 단계는 `hero / display / title / date / heading / quote / lead / body / label / caption` (값은 `tokens.css`).

### 말투
결과 먼저, 이유는 한 문장. 과장·이모지·느낌표 없음. 안 된 일에는 다음에 할 수 있는 일을 붙인다.
예: "케미는 좋지만 겹치는 시간이 없어요. 가능한 시간을 늘리면 다시 시도할 수 있어요."

## 7. 디자인 시스템 구조

```
당근 Seed Design (기반)            큐피트 (얹은 것)
────────────────────────          ─────────────────────────────
회색 단계, 간격, 모서리      →    그대로 사용
브랜드 의미 토큰(bg/fg/stroke) →  로즈 레터로 다시 선언 (tokens.css)
ActionButton, Chip, TextField,    그대로 사용 (색만 따라옴)
Badge, Callout
                                  고유 모양: 초대장 · 대본 · 결과 장부 · 시간표 · 도장
                                  고유 배치: 왼쪽 고정 제목 + 오른쪽 내용
                                  3D 배경(두 점과 그물) · 스크롤 연출
```

Seed의 의미 토큰(`--seed-color-bg-brand-solid` 등 9개)을 `.cq` 범위에서 다시 선언하기 때문에, Seed 컴포넌트를 고치지 않고도 색이 바뀐다. Seed를 올려도 이 파일 하나만 확인하면 된다.

## 8. 아직 정하지 않은 것

- 이름 "큐피트"와 로고는 임시안이다. 상표 확인을 하지 않았다.
- 어두운 화면(다크 모드) 색.
- 사진을 쓸지, 쓴다면 어떻게 쓸지. 지금은 사진이 전혀 없다.
- 앱 아이콘, 알림·이메일 같은 화면 밖 접점.
- 색은 화면 캡처로만 확인했다. 실제 사용자 반응은 확인하지 않았다.
